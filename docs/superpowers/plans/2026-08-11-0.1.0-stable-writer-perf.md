# v0.1.0-stable 写吞吐优化与保真实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-performance, rust-testing

**Goal:** 解决 writer 超线性增长问题，将 1000 行写入从 ~1.6s 降至 <500ms，同时保持 byte-equal 保真。

**Architecture:** `docs/easydoc-rust-Architecture.md`

**Tech Stack:** Rust 1.88+, criterion, flamegraph

- MSRV 1.88.0
- `unsafe_code = "forbid"` 全 workspace
- 不得破坏现有 635+ 测试
- benchmark 数字必须更新到 RESULTS.md

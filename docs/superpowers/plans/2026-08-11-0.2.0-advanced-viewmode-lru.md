# v0.2.0 高级 ViewMode 与 LRU 缓存 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-performance, rust-module-layout

**Goal:** 扩展 ViewMode 至 8 种（新增 Diff / Search / Summary / Table），实现 LRU 文档缓存，提升重复读取性能。

**Architecture:** `docs/easydoc-rust-Architecture.md`

**Tech Stack:** Rust 1.88+, lru crate, criterion

## Global Constraints

- MSRV 1.88.0
- `unsafe_code = "forbid"` 全 workspace
- pedantic clippy 全开 + `missing_docs = "warn"`
- 新增 ViewMode 必须向后兼容

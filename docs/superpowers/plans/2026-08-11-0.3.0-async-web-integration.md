# v0.3.0 Async API 与 Web 框架集成 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-web, rust-concurrency

**Goal:** 新增 async tokio API 层、web 框架集成 crates（axum / actix-web / warp）、template DSL，支持高并发文档处理服务。

**Architecture:** `docs/easydoc-rust-Architecture.md`

**Tech Stack:** Rust 1.88+, tokio, axum, actix-web, warp, serde

## Global Constraints

- MSRV 1.88.0
- `unsafe_code = "forbid"` 全 workspace
- pedantic clippy 全开 + `missing_docs = "warn"`
- async API 必须与同步 API 100% 功能对等
- web 框架集成必须 feature-gated

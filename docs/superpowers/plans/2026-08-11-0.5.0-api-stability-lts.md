# v0.5.0 API 稳定化与 LTS 候选 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-code-review, rust-semver

**Goal:** 完成 Rust API Guidelines audit、API 稳定化、LTS RFC、发布 0.5.0 候选版本。

**Architecture:** `docs/easydoc-rust-Architecture.md`

**Tech Stack:** Rust 1.88+, cargo-semver-checks, cargo-api-guidelines

## Global Constraints

- MSRV 1.88.0
- `unsafe_code = "forbid"` 全 workspace
- pedantic clippy 全开 + `missing_docs = "warn"`
- 所有公开类型必须有文档注释
- 所有公开方法必须有示例代码

---

### Task 1: Rust API Guidelines Audit

> Files:
> - Create: `docs/api-guidelines-audit.md`
> - Modify: 各 crate `src/lib.rs`

**Steps:**
- [ ] 逐条检查 Rust API Guidelines（https://rust-lang.github.io/api-guidelines/）
- [ ] 检查命名规范（C-CASE / C-WORD-ORDER）
- [ ] 检查互操作性（C-INTEROP / C-SERDE / C-SMART-PTR）
- [ ] 检查健壮性（C-VALIDATE / C-ERROR / C-DTOR-DO-NOT-FAIL）
- [ ] 检查文档（C-DOC-EXAMPLES / C-LINK）
- [ ] 检查打包（C-FEATURE / C-MUST-USE / C-RELNOTES）
- [ ] 生成审计报告

# v0.1.0-stable MD→DOCX 完整覆盖 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-testing, rust-code-review

**Goal:** 补齐 MD→DOCX 的缺失元素（HTML 标签、脚注、删除线、数学公式），平衡 start_number 列表嵌套，达到 1000+ 测试、API 冻结。

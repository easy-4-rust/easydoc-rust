# v0.2.0 生态工具（Phase 5）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-cli, rust-workspace

**Goal:** 实现 Roadmap Phase 5 的生态工具：easydoc-cli 命令行工具、easydoc-mcp 增强、easydoc-web 响应适配器、完整 benchmark 套件、测试 fixture 集合。

**Architecture:** `docs/easydoc-rust-Architecture.md`

**Tech Stack:** Rust 1.88+, clap, criterion, serde_json

## Global Constraints

- MSRV 1.88.0
- `unsafe_code = "forbid"` 全 workspace
- pedantic clippy 全开 + `missing_docs = "warn"`
- CLI 必须有 man page 和 shell 补全

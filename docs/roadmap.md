# Roadmap

## 0.1 — 简单 DOCX 生成

- [x] 独立文档中间模型
- [x] `EasyDoc` Builder 与 `DocxWriter`
- [x] 标题、段落、富文本 Run 和分页
- [x] 字体、字号、颜色、加粗、斜体、下划线和对齐
- [x] A4 页面、页边距、强类型单位和中文字体槽位
- [x] 表格、嵌套块、表头样式和横向合并
- [x] 块级与行内图片
- [x] 显式 `finish()` 与类型化错误
- [x] DOCX ZIP/XML 集成测试

## 0.2 — 页面与样式完善

- [ ] 行距、段前段后、边框和背景色
- [ ] 表格列宽、单元格边距、纵向合并和重复表头
- [ ] 页眉、页脚、页码、编号和项目符号
- [ ] 命名样式输出到 DOCX styles.xml
- [ ] 输出临时文件后原子替换目标文件

## 0.3 — EasyExcel 式扩展

- [ ] `WriteContext` 和有序 `WriteHandler` 生命周期
- [ ] `IntoTableRow` 数据转换契约
- [ ] `#[derive(DocxRow)]` 派生宏
- [ ] 输出资源限制、图片限制和包大小 Guardrails
- [ ] async 适配层（核心渲染仍保持同步、确定性）

## 0.4 — 模板与有限读取

- [ ] 段落、Run、表格的只读映射
- [ ] 跨 Run 的文本占位符替换
- [ ] 列表、条件块和图片变量
- [ ] 保留未知 XML、媒体、关系和样式的包级模板变换
- [ ] 恶意 ZIP/XML 输入的资源限制和回归语料库

## 非目标

- 旧式 `.doc` 二进制格式
- 完整 Word 排版/渲染引擎
- DOCX 到 PDF 的像素级转换
- 公式重新计算、协同编辑和完整修订跟踪
